Connect to your GitHub repository to edit the website. Changes are saved as a commit and go live in about a minute.

How do I get a token? (one-time, 1 minute)
  1. Open GitHub → Fine-grained token.
  2. Name it website editor, choose an expiry date.
  3. Repository access → Only select repositories → pick this website repository.
  4. Permissions → Repository → Contents: Read and write. (Optional: Actions: Read and write to run the LinkedIn sync button.)
  5. Generate, copy, paste it here.

The token stays in this browser only. Never share it.
